# Spotalk

אפליקציית אנדרואיד לשליטה ב-Spotify בממשק כהה, עם עוזר קולי: אומרים שם של שיר, אמן או פלייליסט, והוא מתנגן.

## פיצ'רים

### שליטה ב-Spotify
- התחברות רשמית ל-Spotify (Authorization Code + PKCE, בלי client secret).
- **בית:** ברכה לפי שעה, קיצורים לפלייליסטים ו"הושמעו לאחרונה".
- **חיפוש:** שירים, אמנים, אלבומים ופלייליסטים, עם חיפושים אחרונים.
- **ספרייה:** פלייליסטים, אלבומים, אמנים ו"שירים שאהבתי".
- **מסכי אלבום, פלייליסט ואמן** (באמן: תמונה גדולה, אלבומים וסינגלים).
- **נגן קטן ונגן מלא:** ניגון והשהיה, הבא והקודם, גלילה בשיר, ערבוב, חזרה ולייק.
- **תור השמעה:** הוספת שיר לתור מכל רשימה.
- **הוספה לפלייליסט** מתפריט השיר.
- כפתור "פתח ב-Spotify" וייחוס ל-Spotify.

### תמונות
כברירת מחדל מוצגות כל התמונות. בהגדרות יש אזור **"תמונות וסימון אמנים"** שמוגן בקוד (בפעם הראשונה קובעים קוד של 4 ספרות ומעלה; אם שוכחים אותו אפשר רק למחוק את נתוני האפליקציה). אחרי שפותחים אותו אפשר:
- **לבחור מצב תמונות:** כל התמונות / **רק זמרים גברים** / בלי תמונות בכלל.
- **לסמן אמן ידנית** כ**גבר** או כ**אישה**: מחפשים אמן ולוחצים. הסימון גובר על הזיהוי האוטומטי ונשמר בטלפון. יש רשימה של כל מי שסומן, עם אפשרות לבטל.

במצב "רק זמרים גברים" תמונה מוצגת רק כשכל האמנים זוהו כגברים. זמרות, להקות מעורבות ולא ידוע מקבלים משבצת צבע עם אייקון. המגדר מזוהה אוטומטית מ-Wikidata ו-MusicBrainz ונשמר בטלפון. המצב חל גם על Android Auto.
יש גם מתג "כל העטיפות באותו צבע" (גלוי לכולם).

### עוזר קולי
- **מיקרופון** בבית ובתיבת החיפוש. ההקשבה מסתיימת לבד כשמפסיקים לדבר, או אחרי X שניות לכל היותר (ברירת מחדל 3, סרגל בהגדרות מ-1 עד 10). ואז מחפשים ומנגנים את התוצאה הראשונה.
- **ווידג'ט** למסך הבית: לחיצה פותחת ישר את ההקשבה.
- **עוזר דיגיטלי של המכשיר:** מגדירים את Spotalk כעוזר, ואז לחיצה ארוכה על כפתור ההפעלה פותחת את ההקשבה.
- **עובד גם במסך נעילה** (חלון ההקשבה מופיע מעל הנעילה).
- **ניגון מהרקע:** מהווידג'ט ומכפתור ההפעלה האפליקציה לא נפתחת. השיר מתנגן ורואים הודעה קצרה. מתג בהגדרות קובע אם Spotify נפתחת על השיר בסיום (במסך נעילה היא לא נפתחת).
- **עברית ואנגלית:** מתג בהגדרות לזיהוי דיבור באנגלית (טוב לשירים עם שם באנגלית).

**מה אפשר לומר:**

| אומרים | מה קורה |
|---|---|
| "תנגן את X" / "נגן X" / "תשמיע לי X" | מנגן את השיר |
| "תחפש את השיר X" / "חפש X" / "תמצא לי X" | מחפש ומנגן את הראשון |
| "X" בלבד | מחפש ומנגן את הראשון |
| "תנגן את הפלייליסט X" / "רשימת השמעה X" | מנגן פלייליסט שלם מההתחלה. קודם מחפשים בין הפלייליסטים שלך (גם אם הזיהוי לא מדויק), ואם אין התאמה מחפשים ב-Spotify |
| "תוסיף לתור X" / "הוסף את X לתור" | מוסיף לתור בלי להפסיק את מה שמתנגן |
| "play X", "search for X", "play playlist X", "add X to queue" | אותו דבר באנגלית |

**הבנת הבקשה עם AI (אופציונלי):** בהגדרות מדביקים מפתח API חינמי של Gemini מ-https://aistudio.google.com/apikey. לפני החיפוש Gemini מתקן טעויות זיהוי, מבין שמות באנגלית שנאמרו בעברית, ומזהה שיר לפי תיאור. אם הוא לא עונה, החיפוש ממשיך לפי מה שנשמע. יש כפתור "בדיקת חיבור ל-AI". כשמפתח מוגדר, הטקסט שנאמר נשלח ל-Google.

### YouTube Music
מתג בהגדרות, "נגן ב-YouTube Music", שולח את הבקשה הקולית ל-YouTube Music במקום Spotify (שיר, אמן או פלייליסט). האפליקציה מוצאת את השיר דרך החיפוש הלא-רשמי של YouTube Music ופותחת אותו ישר בנגן. הוספה לתור לא נתמכת שם, ו-YouTube Music נפתחת במקום לנגן ברקע.

### Android Auto
האפליקציה מופיעה ברכב כאפליקציית מדיה: **שירים שאהבתי**, **פלייליסטים**, **הושמעו לאחרונה** וחיפוש, עם ניגון, השהיה, הבא והקודם, ועטיפה של השיר המתנגן (לפי מצב התמונות שנבחר). אפשר גם בקול: "היי גוגל, תנגן X ב-Spotalk". הניגון נעשה ב-Spotify שבטלפון.

אפליקציה שלא הותקנה מחנות Play לא מופיעה ב-Android Auto כברירת מחדל:
1. בהגדרות Android Auto לוחצים 10 פעמים על "גרסה" ומאשרים מצב מפתחים.
2. בתפריט שלוש הנקודות ← **הגדרות מפתח** ← מסמנים **מקורות לא מוכרים**.
3. מחברים לרכב, והאפליקציה מופיעה במגירת האפליקציות.

### כלים
- קובץ לוגים לשיתוף מההגדרות, ומספר הגרסה המותקנת.

## בנייה והגדרה (פעם אחת)

האפליקציה לא כוללת שום פרטים אישיים. כל אחד בונה לעצמו ומגדיר פרטים משלו:

### 1. אפליקציה בדשבורד של Spotify
1. נכנסים ל-https://developer.spotify.com/dashboard ויוצרים אפליקציה (**Create app**).
2. ב-**Redirect URIs** מוסיפים בדיוק: `spotalk://callback`
3. מסמנים **Android** ו-**Web API**.
4. בהגדרות ה-Android מוסיפים: Package name `com.example.spotalk` ואת ה-SHA1 של המפתח שבו חותמים (שלב 3). שם החבילה הוא ברירת מחדל, אפשר להחליף אותו בשם משלך ב-`applicationId` וב-`namespace` בקובץ `app/build.gradle.kts` (ואז גם לרשום אותו בדשבורד).
5. ב-**User Management** מוסיפים את המייל של חשבון ה-Spotify שלך.
6. את ה-**Client ID** מדביקים אחר כך בתוך האפליקציה (הוא לא כתוב בקוד).

### 2. בנייה
**במחשב:** פותחים ב-Android Studio ומריצים, או: `./gradlew assembleDebug`. הקובץ: `app/build/outputs/apk/debug/app-debug.apk`.

**ב-GitHub:** עושים Fork, ואז Actions ← **Build APK** ← **Run workflow**. הקובץ `Spotalk.apk` נבנה ועולה ל-Releases (תג `latest`). הבנייה לא רצה אוטומטית.

### 3. מפתח חתימה ו-SHA1
Spotify מזהה את האפליקציה לפי ה-SHA1 של מפתח החתימה, ולכן הוא חייב להישאר קבוע.
- **בנייה במחשב:** `./gradlew signingReport` מדפיס את ה-SHA1 של מפתח ה-debug שלך.
- **בנייה ב-GitHub:** יוצרים מפתח משלך ושומרים אותו כסוד:
  ```
  keytool -genkeypair -keystore spotalk.p12 -storetype PKCS12 -alias spotalk -keyalg RSA -keysize 2048 -validity 10000
  base64 -w0 spotalk.p12
  ```
  ב-Settings ← Secrets and variables ← Actions יוצרים שני Repository secrets: `KEYSTORE_BASE64` (הפלט של base64) ו-`KEYSTORE_PASSWORD` (הסיסמה, אותה סיסמה למפתח ולקובץ). את ה-SHA1 מקבלים עם `keytool -list -v -keystore spotalk.p12`. שומרים את הקובץ במקום בטוח ולא מעלים אותו לריפו.

### 4. הפעלה ראשונה
מתקינים, פותחים, מדביקים את ה-Client ID, שומרים ומתחברים. את מפתח ה-AI (Gemini) אפשר להוסיף בהגדרות, אופציונלי.

## דרישות
- Spotify Premium לבעל האפליקציה בדשבורד.
- אפליקציית Spotify מותקנת ומחוברת בטלפון.
- Android 8.0 ומעלה.

## מגבלות ידועות
- **מצב פיתוח של Spotify:** רק משתמשים שהוספת ב-User Management יכולים להתחבר (מספר קטן). להפצה לכולם צריך אישור Extended Quota מ-Spotify.
- בפלייליסטים שאינם שלך Spotify לא מחזירה את רשימת השירים במצב פיתוח. אפשר עדיין לנגן אותם.
- חיפוש מחזיר עד 10 תוצאות לכל סוג.
- ה"שירים הפופולריים" של אמן הוסרו מה-API, ולכן בעמוד אמן מוצגים אלבומים וסינגלים.
- YouTube Music: החיפוש לא רשמי ועלול להפסיק לעבוד.

## פרטיות
ההגדרות, הטוקנים, מפתח ה-AI וסימוני האמנים נשמרים רק בטלפון, וגיבוי אנדרואיד כבוי. מידע יוצא החוצה רק ל: Spotify (כל השימוש), Google (זיהוי דיבור, ואם הוגדר מפתח גם Gemini), Wikidata ו-MusicBrainz (זיהוי מגדר, רק מזהה אמן, ורק במצב "רק זמרים גברים") ו-YouTube Music (אם הופעל).

## ייחוס
ההנחיות של Spotify מבקשות להציג את הלוגו הרשמי ליד התוכן. אפשר להוריד אותו מ-https://developer.spotify.com/documentation/design ולשים אותו במקום הטקסט ב-`SpotifyAttribution` בקובץ `ui/Components.kt`.
